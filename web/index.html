Bot 如何决定下一发？

利用已知命中、落空和剩余舰长筛选候选布局，追击时计算整支舰队相互不重叠的可能布局；残局较小时穷举。Bot 无法读取敌方未公开的舰船位置。

怎样看回放？

对局结束后可以保存 JSON 回放，也会自动存到项目 replays 目录。打开回放后拖动进度条逐步查看。回放含双方完整舰队，仅用于赛后分析。
